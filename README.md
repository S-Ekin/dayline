# DayLine 时间轴插件

飞书多维表格仪表盘插件：通过 **24 小时时间轴**记录某一天发生的所有任务事件，如同一整天的轨迹。

- 时间轴（垂直轴线）**居中**；**左侧**为小时刻度与**时间点**任务（通过**曲线**连接到轴线），**右侧**为**时间区间**任务
- 事件**图标常显**；悬停时以**两行标签**（名称 / 加粗时间）显示，标签置顶不被遮挡
- 区间条高度 = 开始到结束时间映射到刻度的实际长度
- 支持**跨天**：结束/开始晚于当天时，时刻自动 +24，时间轴刻度相应延长（如 24、25、26…）
- 时间轴**仅显示有任务的范围**（从最早到最晚任务，取整点边界），无任务空档不显示
- 有**开始时间 + 结束时间**的记录 → 时间区间；只有**开始时间** → 时间点
- 点击事件可查看该条记录的详情
- 支持同时选择**多个记录表**，各表独立配置字段

## 数据筛选条件

1. **记录表**：可同时选择多张记录表，每张表单独配置
2. **日期**：支持快捷 **今天 / 昨天 / 前天**，也可自定义指定日期；每张表需指定一个日期字段用于匹配所选日期
3. **展示字段**：选择要展示的字段（如“事件任务列”），其值成为时间轴上的事件；每个事件可单独配置图标与颜色

## 每个表的字段配置

| 配置项 | 说明 |
| --- | --- |
| 日期字段 | 必填，用于匹配所选日期（是否为今天/昨天/前天） |
| 展示字段 | 事件/任务列，其值成为时间轴上的事件标签 |
| 开始时间字段 | 可选，有值则按该时刻定位 |
| 结束时间字段 | 可选，与开始字段同时有值则为时间区间，否则为时间点 |

## 数据来源

插件通过多维表格 SDK 直接读取各选中表的全部记录，在本地按所选日期筛选并构建时间轴。

- 添加记录表时自动识别字段：优先取日期时间字段为日期字段、文本字段为展示字段
- 所选日期变化后无需重新拉取，本地即可重新筛选

## 本地开发

```bash
# Node 16.19+（部署环境为 16.19.0）
npm install
npm run dev      # 本地调试
npm run build    # 产物输出到 dist（package.json 已设置 output: dist）
```

## 在仪表盘中使用

1. 新建 / 打开仪表盘 → 添加组件 → 更多 → 添加自定义插件
2. 填入本地 dev 地址或部署后的 `dist` 静态地址
3. 在右侧配置：
   - 标题与图标
   - 记录表（可多选），及每张表的日期字段 / 展示字段 / 开始与结束时间字段
   - 日期快捷方式（今天 / 昨天 / 前天 / 自定义）
   - 事件图标与颜色、布局参数
4. 点击「确定」进入展示态；顶部工具条可随时切换日期与刷新
